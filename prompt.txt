==================================================
六. Group 内部 Benchmark 权重
==================================================

默认情况下:

Group 内部 benchmark 平均分配权重.

Insignificant IO:

fannkuch-redux = 1 / 3
n-body = 1 / 3
spectral-norm = 1 / 3

Significant IO:

mandelbrot = 1 / 4
fasta = 1 / 4
k-nucleotide = 1 / 4
reverse-complement = 1 / 4

最终 benchmark 权重:

benchmarkWeight =
groupWeight × benchmarkInternalWeight

例如:

Insignificant IO = 50%

则:

每个 Insignificant IO benchmark:

50% / 3 = 16.67%

Significant IO = 50%

则:

每个 Significant IO benchmark:

50% / 4 = 12.5%

==================================================
七. Ranking 算法
==================================================

必须使用:

Weighted Geometric Mean

不要使用普通 Arithmetic Mean.

每个 benchmark 中:

multiplier 越小越好.

例如:

C gcc = 1.0x
Rust = 1.2x
Go = 2.0x
Python = 30x

对于某个语言:

score = exp(
  Σ(weight_i × ln(multiplier_i))
)

最终:

score 越小越好.

排名从小到大排序.

显示:

Rank
Language / Implementation
Score
Relative Performance

例如:

1    C gcc       1.08x
2    Rust        1.15x
3    C++ g++     1.22x
4    Go          1.85x
5    Java        2.30x

因此 Ranking 算法必须正确处理缺失数据.

但是必须重新归一化该语言参与计算的权重.

例如:

原始可用 benchmark 权重:

0.15
0.15
0.20
0.20

总权重:

0.70

重新归一化:

0.15 / 0.70
0.15 / 0.70
0.20 / 0.70
0.20 / 0.70

然后再计算 Weighted Geometric Mean.

同时 UI 必须显示:

例如:

或者:

6 / 7 benchmarks

Coverage 较低的语言需要视觉提示.

==================================================
二十一. Ranking 算法实现
==================================================

创建:

lib/ranking.ts

实现函数:

calculateRanking(
  groups,
  weights
)

算法:

1. 获取所有 benchmark.

2. 根据 Group Weight 计算每个 benchmark 权重.

3. 收集所有语言 implementation.

4. 对每个语言:

获取它存在的 benchmark multiplier.

5. 如果 multiplier 不存在:

跳过该 benchmark.

6. 计算实际参与 benchmark 的总权重.

7. 对参与 benchmark 的权重进行重新归一化.

8. 使用:

exp(sum(weight × log(multiplier)))

计算 score.

9. score 越小排名越高.

10. 返回排序后的 LanguageScore[].

必须:

避免 log(0).

必须:

过滤:

null
undefined
NaN
Infinity
非正数
